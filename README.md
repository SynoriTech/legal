# SynoriTech legal pages

Static privacy, terms, and support pages published with GitHub Pages.

## URL convention

Each app uses `https://synoritech.github.io/legal/<slug>/{privacy,terms,support}.html`.
The repository name is lowercase in the public URL; GitHub Pages paths are case-sensitive.

App slugs added in this change:

- `land-measure`
- `sunmoon-planner`
- `paycheck-budget`
- `alarmonce`

The existing `cleflark` and `dosechime` pages remain available and are linked
from the site index.

`support.html` is the shared support directory. Product-specific support URLs should still point to each app's own support page.
